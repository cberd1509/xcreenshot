How it works

⌃⇧⌘S PrtSc

Press the shortcut

The screen freezes the moment you press it, so menus and hover states stay put.

1260 × 1064

Drag a region

Add arrows, boxes, text, a highlighter or a blur. Undo with ⌘ZCtrl+Z.

⌘C⌘S CtrlCCtrlS

Copy or save

Paste it anywhere at the size you saw it, or save a PNG.

Install

Signed and notarized by Apple. It updates itself, and you can turn that off in Settings.

It updates itself, and you can turn that off in Settings. It isn't code signed yet, so Windows asks before the first run.

  1. 01Download the .dmg and open it.
  2. 02Drag xcreenshot to Applications, then open it.
  3. 03Allow Screen Recording when it asks. That's it: press ⌃⇧⌘S
  1. 01Download the installer and run it.
  2. 02If Windows says it protected your PC, click More info › Run anyway.
  3. 01It isn't out yet. On GitHub, click Watch › Custom › Releases to get an email when it is.
  4. 02Once it's out: download the installer from Releases and run it.
  5. 03Press PrtSc to take a screenshot, or Ctrl Shift PrtSc if Snipping Tool already uses PrtSc.

Small on purpose

A handful of settings: your shortcut, whether it remembers the last region, a magnifier for exact pixels, and whether it opens at login.
