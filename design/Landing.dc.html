The screen freezes the moment you press it, so menus and hover states stay put.
1260 × 1064

Or double-click a window to take all of it. Add arrows, boxes, text, a highlighter or a blur. Undo with {{undo}}.

Paste it anywhere at the size you saw it, or at 2×, 3× or 4×. Save a PNG or share it.

Install

macOS Windows

Signed and notarized by Apple. It updates itself, and you can turn that off in Settings.

It updates itself, and you can turn that off in Settings. It isn't code signed yet, so Windows asks before the first run.
  1. 01Download the .dmg and open it.
  2. 02Drag xcreenshot to Applications, then open it.
  3. 03Allow Screen Recording when it asks. That's it: press ⌃⇧⌘S
  1. 01Download the installer and run it.
  2. 02If Windows says it protected your PC, click More info › Run anyway.
  3. 03Press PrtSc to take a screenshot, or Ctrl Shift PrtSc if Snipping Tool already uses PrtSc.

Small on purpose

A handful of settings: your shortcut, quick copy for when you just need a copy, whether it remembers the last region, a magnifier for exact pixels, and whether it opens at login.
